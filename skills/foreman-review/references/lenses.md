# Specialist lenses

Select only materially relevant lenses. Record one cited reason and one unresolved hypothesis for each.

- Intent and correctness: requirements, invariants, main and failure paths.
- Security and privacy: trust, authorization, injection, secrets, sensitive data.
- Data and concurrency: schema, migrations, transactions, consistency, races, retries.
- Contract and compatibility: APIs, serialization, configuration, callers, versioning.
- Frontend and accessibility: flows, rendering, keyboard and screen readers, responsive behavior.
- Reliability and operations: deployment, observability, timeouts, limits, recovery.
- Architecture: ownership, coupling, data flow, blast radius, costly lock-in.

Ask one targeted question per unresolved hypothesis. Add a followup only for new material risk, missing evidence, or contradiction. Stop the lens when routed risks are resolved. Never semantically repeat static or skeptic coverage.
